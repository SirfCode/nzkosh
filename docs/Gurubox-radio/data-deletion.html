Local Data and Deletion

GuruBox Radio does not create user accounts and does not maintain a server-side profile that requires an account-deletion request.

Delete diagnostics

Open GuruBox Radio, open the app menu, choose Diagnostics, and select Clear.

Delete all app-local information

Use Android Settings to open GuruBox Radio's storage settings and choose Clear storage, or uninstall the app. This removes local preferences and diagnostic files stored by the app.

Previously shared files

If you exported a diagnostic file to WhatsApp, email, cloud storage or another application, deleting GuruBox Radio data does not delete the copy held by that destination. Use that service's deletion controls or contact its provider.
